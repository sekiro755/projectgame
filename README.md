# Дурак Неон — «Дурак» для ВК Игры

Карточная игра «Дурак» (подкидной и переводной) для платформы VK Mini Apps / ВК Игры.
Чистый HTML/CSS/JavaScript без фреймворков и сборщиков, архив весит ~64 КБ.
Карты, рубашки и столы нарисованы на CSS, звуки синтезируются через Web Audio — внешних ассетов нет.

## Что внутри

- **Правила**: колода 36 карт, 2–4 игрока (ты + боты), режимы «Подкидной» и «Переводной».
  Козырь — последняя карта колоды, первым ходит младший козырь. Подкидывание по достоинствам
  (не больше 6 и не больше, чем карт у отбивающегося), подкидывание после «Беру», перевод
  (до первого отбоя, с проверкой, хватит ли карт у следующего), добор по очереди
  (атакующий первым, отбивающийся последним), выход игроков при пустой колоде, ничья.
- **Боты**: «Новичок» (случайные допустимые ходы), «Норм» (минимальный отбой, бережёт козыри),
  «Профи» (помнит вышедшие и взятые карты, считает вероятность отбоя, подкидывает то, чем соперник
  вероятно не отобьётся). Имена, эмодзи-аватарки и безобидные реплики в облачках.
- **Стиль**: тёмная тема, неон, анимации раздачи, полёта карт и отбоя, drag & drop и тап.
  Эмодзи-реакции 😂🔥💀👀🤡 в соперников.
- **Прогресс**: уровни и ранги («Салага» → «Шарящий» → «Козырный» → «Легенда двора» → «Король подкидного»),
  ежедневные задания, бонус за вход 7 дней подряд, серия побед, статистика.
- **Скины**: «Неон», «Космос» (открыты сразу), «Аниме-закат», «Пиксель 8-бит», «Граффити» —
  за уровень, игровые монеты или просмотр рекламы. Рубашку и стол можно выбирать отдельно.
- **VK Bridge**: `VKWebAppInit`, `VKWebAppGetUserInfo`, `VKWebAppStorageGet/Set` (с запасным localStorage),
  `VKWebAppShowWallPostBox`, `VKWebAppShowStoryBox` (картинка 1080×1920 рисуется на canvas),
  `VKWebAppShowInviteBox`, `VKWebAppAddToFavorites` (после 3-й партии), `VKWebAppTapticImpactOccurred`.
- **Реклама** (`js/ads.js`): `showInterstitial()`, `maybeShowInterstitial()`, `showRewarded(onReward)`.
  Перед показом всегда `VKWebAppCheckNativeAds`. Межстраничная — только между партиями, не раньше 2-й
  партии сессии и не чаще раза в 3 партии. За вознаграждение: x2 монет за победу, открыть скин,
  «Второй шанс» (вернуть взятую кучу, раз за партию), бонусные монеты в меню (5 в день).
  Нет рекламы — кнопка показывает «Реклама пока недоступна», игра не ломается.
- **Модерация 12+**: никаких ставок, лутбоксов и покупок за реальные деньги; все награды фиксированные.

## Структура проекта

```
index.html            — разметка всех экранов
style.css             — стили, скины рубашек и столов
js/engine.js          — правила игры (чистая логика, без DOM)
js/bots.js            — ИИ ботов трёх уровней
js/progress.js        — монеты, опыт, ранги, скины, задания, бонусы, сохранение
js/vk.js              — обёртка над VK Bridge с таймаутами и запасными вариантами
js/ads.js             — вся реклама
js/sound.js           — синтезированные звуки
js/game.js            — интерфейс: экраны, отрисовка, анимации, ввод
js/vendor/            — локальная копия vk-bridge (если CDN недоступен) и её лицензия MIT
tests/engine.test.js  — тесты правил на крайние случаи
tests/simulate.js     — тысячи партий бот-против-бота: проверка правил и силы ботов
pack.sh               — сборка dist/ и архива durak-neon.zip
vk-hosting-config.json — настройки для загрузки через vk-miniapps-deploy
```

## Структура архива для загрузки в ВК

`index.html` должен лежать **в корне архива**, а не во вложенной папке:

```
durak-neon.zip
├── index.html
├── style.css
└── js/
    ├── engine.js
    ├── bots.js
    ├── vk.js
    ├── sound.js
    ├── progress.js
    ├── ads.js
    ├── game.js
    └── vendor/
        ├── vk-bridge.min.js
        └── vk-bridge.LICENSE
```

Собрать: `sh pack.sh` (или `npm run pack`). Без терминала: выделите `index.html`, `style.css`
и папку `js` → «Сжать в ZIP-архив». Папку `tests` и служебные файлы класть не нужно.

## Локальный запуск и проверка

```bash
python3 -m http.server 8080        # затем открыть http://localhost:8080
npm test                           # тесты правил + симуляция 1000 партий на каждый вариант
```

- `http://localhost:8080/?mockads=1` — имитация рекламы вне ВК (можно проверить все рекламные кнопки).
- Вне ВК Bridge недоступен: прогресс сохраняется в localStorage, «Поделиться» копирует текст.
- Сбросить прогресс: в консоли браузера `localStorage.clear()` и перезагрузить страницу.

## Как выложить игру во ВКонтакте

Названия разделов в кабинете разработчика иногда меняются — ориентируйтесь на смысл шагов.
Актуальная документация: <https://dev.vk.ru/mini-apps/overview>.

### 1. Создать приложение
1. Откройте <https://dev.vk.ru> → «Мои приложения» → «Создать».
2. Выберите платформу **«Игра»** (VK Mini Apps / ВК Игры), введите название «Дурак Неон», создайте.
3. Запомните **ID приложения** (`app_id`) — он понадобится для загрузки.

### 2. Загрузить игру на хостинг ВК
Вариант А — через официальную утилиту (рекомендуется):
1. Установите Node.js 18+.
2. Впишите ID в `vk-hosting-config.json`: `"app_id": "1234567"`.
3. Выполните `npm run deploy` (соберёт `dist/` и запустит `@vkontakte/vk-miniapps-deploy`).
4. Утилита попросит подтвердить вход через ВК и выбрать окружение. Загрузите сначала в **dev**
   (тестовая версия), после проверки — в **production**.

Вариант Б — свой хостинг: распакуйте архив на любой HTTPS-хостинг и в настройках приложения
укажите адрес `index.html` для всех версий (мобильная, m.vk, десктоп).

Вариант В — если в настройках вашего приложения есть загрузка архива в хостинг ВК,
загрузите туда `durak-neon.zip` (с `index.html` в корне).

### 3. Протестировать
1. Пока приложение не опубликовано, оно видно только администраторам и тестировщикам —
   добавьте друзей в раздел тестировщиков в настройках приложения.
2. Откройте `https://vk.ru/app<ID>` на компьютере и в мобильном приложении ВКонтакте.
3. Проверьте: имя и аватар подтянулись, прогресс сохраняется после перезапуска (VK Storage),
   работают «Поделиться» (история и стена), «Пригласить друзей», вибрация на телефоне.
4. До подключения монетизации реклама обычно недоступна — убедитесь, что кнопки показывают
   «Реклама пока недоступна» и игра не ломается.

### 4. Отправить на модерацию
1. Заполните карточку: описание, категория «Игры → Карточные», иконка, обложка и скриншоты
   вертикального формата (их удобно снять прямо из игры).
2. Укажите возрастную маркировку **12+**. В игре нет азартных механик, покупок за деньги, мата и
   неприемлемого контента; все награды фиксированные.
3. Выберите production-версию и отправьте приложение на модерацию. После одобрения опубликуйте его
   в каталоге.

### 5. Подключить рекламную монетизацию
1. В настройках приложения откройте раздел монетизации, примите условия и заполните реквизиты
   для выплат.
2. Включите нативную рекламу: межстраничную (interstitial) и за вознаграждение (rewarded).
3. Код уже готов: `js/ads.js` перед каждым показом вызывает `VKWebAppCheckNativeAds`, затем
   `VKWebAppShowNativeAds` с `ad_format: "interstitial"` или `"reward"`. Частоту межстраничной
   рекламы настраивают константы в начале `js/ads.js`.
4. После включения проверьте в мобильном приложении: x2 монет на экране победы, открытие скина,
   «Второй шанс» и бонусные монеты в меню.

## Как устроен код

- `engine.js` — состояние партии в виде JSON и функции `attack`, `defend`, `transfer`, `take`, `pass`,
  `resolve`, `pending` (кто должен ходить). Никакого DOM — поэтому правила тестируются в Node.
- `bots.js` — `decide(state, player, level)` возвращает действие. «Профи» видит только публичную
  информацию: сброс, стол, размеры рук и карты, которые соперники забрали со стола.
- `game.js` — после каждого действия перерисовывает стол и анимирует карты методом FLIP
  (запоминает, где карта была, и плавно переносит её в новое место).
